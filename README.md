# Alephdegen Contracts

This repository contains the smart contracts for Alephdegen, a DEX and launchpad built on Alephium.

## Source

The Swap and Pool contracts are forked from [alephium-dex](https://github.com/alephium/alephium-dex), licensed under **LGPL 3.0**.

## Contents

- `Token.ral` — Token contract
- `TokenFactory.ral` — Token factory
- `dex/` — DEX contracts (forked from alephium-dex)
- `scripts/` — Deployment and interaction scripts
- `test/` — Test contracts
- `examples/` — Example contracts
